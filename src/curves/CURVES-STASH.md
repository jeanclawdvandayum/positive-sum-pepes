# CURVES STASH — the zone-curve family (retired from deployment 2026-08-30)

**Status:** not deployable via DeployPSP anymore. Kept in-repo, fully tested,
for future reference — scoopy: "we don't need the other curves (but stash
them for future reference in the repo anyway)." The tilted sine
(`src/libraries/SineMath.sol`) is the one production curve, armed on the
factory at genesis and inherited by every rebirth.
